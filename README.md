## 🚀 Hackathon Project Summary

Out of the three problem statements provided, we confidently chose the **Tourism Explorer** challenge. Our mission was to transcend the traditional search experience by building a **seamless, smart, and interactive ecosystem** that makes travel planning effortless and highly engaging.

By harmonizing **Geoapify's real-time mapping data** with a **Llama-3 powered AI Travel Assistant**, Tourism Explorer acts as a comprehensive, one-stop intelligent trip planner. Users can instantly discover top attractions, museums, and parks around any global location—or directly from their current GPS coordinates.

## 🎨 Interface & User Experience (UX)

We designed the UI with a strong focus on spatial awareness and contextual intelligence:

- 🌌 **Dynamic Hero Section:** A visually striking, gradient-layered world map background that immediately immerses the user, housing a global search bar for instant navigation.
- 🗺️ **Dual-View Architecture:** Users can seamlessly toggle between a rich **List View** of beautiful attraction cards and an immersive **Interactive Map View** to map out their physical surroundings.
- 🤖 **Contextual AI Chat Overlay:** A sleek, floating modal where the AI Assistant (spatially aware of the user's currently viewed city) provides instant, factual travel advice, hidden gems, and local culinary recommendations.
- 📌 **Actionable Itinerary Cards:** Beautifully styled attraction cards that allow users to bookmark locations directly into a personalized, slide-out Trip Itinerary drawer.
- 🎯 **Smart Category Filtering:** Intuitive pill-buttons to instantly sort attractions by Landmarks, Museums, Parks, or Historic Sites.

---

## ⚡ Core Features

- **🧠 Smart AI Travel Guide:** Powered by OpenRouter & Llama 3 for intelligent conversational assistance.
- **📍 Real-Time Interactive Mapping:** Fetches highly accurate points of interest using Geoapify APIs.
- **🛰️ One-Click GPS Tracking:** Hardware-level geocoding to instantly center the explorer around the user.
- **🎒 Personal Trip Builder:** Persistent bookmarking ecosystem for curating a customized travel journey.

## 📦 Setup & Installation

To run this project locally, simply follow these steps:

1. **Clone the repository**
   \\ash
   git clone https://github.com/divyansh9704/tourismexplorer.git
   cd tourismexplorer
   \2. **Install all dependencies**
   \\ash
   npm install
   \3. **Configure Environment Variables**
   Create a \.env\ file in the root directory and add your API keys:
   \\env
   VITE_OPENROUTER_API_KEY=your_openrouter_api_key_here
   \   *(Note: The Geoapify API key is securely handled within the application architecture)*
4. **Boot up the development server**
   \\ash
   npm run dev
   \5. **Build for production** (Optional)
   \\ash
   npm run build
